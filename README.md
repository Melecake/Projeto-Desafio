# nosso cantinho ♡

Um pequeno lugar para guardar os meses que passamos separados.

---

## Como rodar

### 1. Instalar dependências

Na raiz do projeto:
```bash
npm install
```

Na pasta `frontend`:
```bash
cd frontend
npm install
cd ..
```

### 2. Rodar o projeto

Na raiz do projeto:
```bash
npm run dev
```

Isso vai iniciar:
- Backend em `http://localhost:3001`
- Frontend em `http://localhost:5173`

Abra `http://localhost:5173` no navegador.

---

## Dados

Tudo fica salvo em `backend/data.json`.

Não precisa de banco de dados. Basta não deletar esse arquivo.
